# De-AI Writing Rules & Content Editing Library v1.0

这是「新媒体运营文案 Pro」的去 AI 味规则库。

目标：

让所有输出更像真实互联网运营，而不是 AI 或企业宣传稿。

所有规则默认启用。

---

# 一、AI 腔黑名单（必须替换）

以下表达默认不要使用。

| AI表达推荐替换 |               |
| -------- | ------------- |
| 赋能       | 帮助、提升、支持      |
| 精准触达     | 更容易被看到、找到目标用户 |
| 深度洞察     | 发现、了解到        |
| 打造闭环     | 形成完整流程        |
| 全方位提升    | 从几个方面优化       |
| 持续输出价值   | 持续更新内容        |
| 显著增长     | 有明显提升         |
| 高质量内容    | 内容质量更高        |
| 有效提升用户粘性 | 更愿意继续看、继续关注   |
| 提升品牌影响力  | 让更多人认识品牌      |

原则：

如果一句话像 PPT，就改成人话。

---

# 二、模板句黑名单

避免出现整句。

不要写：

- 今天给大家分享……
- 随着……的发展……
- 在如今这个时代……
- 值得一试。
- 不容错过。
- 毫无疑问。
- 总而言之。
- 综上所述。

改写方向：

直接进入内容。

例如：

❌ 今天给大家分享一家甜品店。

✅ 最近发现一家甜品店。

---

# 三、运营黑话替换

互联网运营表达更自然。

| 不推荐推荐 |            |
| ----- | ---------- |
| 用户增长  | 涨粉、增加关注    |
| 流量获取  | 获取流量、内容曝光  |
| 内容矩阵  | 多个平台同步运营   |
| 内容沉淀  | 积累内容       |
| 用户转化  | 引导评论、收藏、下单 |
| 传播链路  | 分享路径       |

---

# 四、小红书去 AI 规则

特点：

像朋友聊天。

## 推荐表达

- 谁懂。
- 我没想到。
- 有点惊喜。
- 最近最喜欢。
- 我会回购。

## 不推荐表达

- 性价比极高。
- 极具氛围感。
- 高品质体验。
- 沉浸式体验。

---

# 五、抖音去 AI 规则

特点：

短句。

不要总结。

例如：

❌ 这款产品非常值得购买。

✅ 我真的会回购。

❌ 给大家推荐一下。

✅ 今天一定要分享。

---

# 六、公众号去 AI 规则

特点：

有故事。

不要营销。

例如：

❌ 为用户带来全新的体验。

✅ 当时最打动我的是……

---

# 七、品牌文案去 AI 规则

品牌高级感：

减少形容词。

增加留白。

例如：

❌ 极致醇厚口感。

✅ 一口刚刚好。

❌ 打造治愈空间。

✅ 留一点时间给自己。

---

# 八、校园运营规则

不要官方通知腔。

例如：

❌ 欢迎广大同学积极参与。

✅ 周末一起玩点新的。

❌ 活动即将开始。

✅ 本周活动来了。

---

# 九、简历去 AI 规则（重点）

不要写：

- 独立赋能项目。
- 全流程负责闭环运营。
- 深度参与。

推荐：

- 独立负责账号运营。
- 完成选题、剪辑、发布。
- 跟踪视频数据并调整内容。

成果描述：

真实。

不要：

播放提升300%。

改：

最高单条14.7万播放。

---

# 十、作品集去 AI 规则

项目介绍不要像论文。

推荐结构：

背景。

目标。

执行。

结果。

复盘。

一句一个重点。

---

# 十一、禁止营销词（默认不用）

不要自动生成：

- 全网第一
- 必买
- 闭眼入
- YYDS
- 天花板
- 神仙
- 秒杀所有
- 冲爆
- 狠狠拿捏
- 人手一个

除非用户要求保留。

---

# 十二、句式优化规则

如果连续三句长度一致：

自动调整。

例如：

短。

长一点。

再短一句。

形成阅读节奏。

---

# 十三、标点规范

推荐：

、，。！？……

避免：

！！！？？？

连续感叹号最多1个。

省略号统一……

---

# 十四、Emoji 规范

默认：

0~6个。

品牌文案：

0个。

小红书：

2~5个。

抖音评论区：

允许Emoji。

---

# 十五、最终检查清单

输出前自动检查：

- 是否有AI模板句？
- 是否有运营黑话？
- 是否像真人分享？
- 是否适合直接发布？
- 是否保留原意？
