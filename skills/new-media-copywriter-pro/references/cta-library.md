# CTA Library v1.0

这是「新媒体运营文案 Pro」的互动引导知识库。

目标：

根据平台和内容类型，自动生成自然、有互动感的 CTA，而不是机械的“点赞收藏关注”。

原则：

- CTA 必须符合内容场景。
- 不强迫关注。
- 不夸张营销。
- 优先引导评论、收藏、分享。

---

# 一、小红书 CTA（重点）

## 评论互动型（★★★★★）

适用于探店、美食、穿搭、韩娱、生活分享。

模板：

- 评论区告诉我你的答案。
- 有没有人和我一样？
- 你会选哪个？
- 最近还有什么推荐？
- 我想看看大家怎么选。
- 有没有同款爱好？
- 评论区交换一下清单。

适用目标：

增加评论率。

---

## 收藏引导型（★★★★★）

适用于攻略、合集、教程。

模板：

- 收藏起来，下次直接用。
- 留着周末去。
- 放进收藏夹慢慢看。
- 下次不知道吃什么就翻出来。
- 建议先收藏。

适用目标：

增加收藏率。

---

## 分享引导型

模板：

- 发给那个最懂你的人。
- 分享给一起去的人。
- 转给你的搭子。

适用目标：

分享率。

---

## 轻互动型

模板：

- 我先收藏了。
- 我已经准备二刷了。
- 轮到你推荐一家。

特点：

聊天感。

# 二、抖音 CTA

特点：

一句话结束。

节奏快。

---

## 评论型

- 评论区见。
- 评论告诉我。
- 停在第几秒？
- 哪一幕最好看？

韩娱：

- 今天谁赢了？
- 最喜欢哪个镜头？

---

## 收藏型

- 收藏下次继续刷。
- 留着以后循环。

---

## 点赞型（少用）

- 点个赞让我知道。
- 喜欢的话告诉我。

默认优先评论，不优先点赞。

---

## 私信型

适用于教程。

模板：

- 私信我发完整版。
- 评论区扣“1”发你。
- 想要模板可以留言。

不要默认生成。

只有教程场景使用。

# 十、CTA 自动选择规则

根据内容目标自动选择：

| 内容目标CTA类型  |         |
| ---------- | ------- |
| 探店         | 评论 + 收藏 |
| 教程         | 收藏 + 私信 |
| 韩娱         | 评论      |
| 校园活动       | 报名      |
| 品牌Campaign | 到店      |
| 公众号        | 留言      |
| 运营干货       | 收藏      |

默认最多输出3条CTA。

不要重复同一种表达。

---

# 十一、禁止 CTA

不要自动生成：

- 点赞关注支持一下。
- 求关注。
- 一键三连。
- 冲冲冲。
- 快买。
- 错过等一年。

除非用户明确要求。

---

# 十二、输出检查

生成CTA前自动检查：

- 是否符合平台？
- 是否符合内容目标？
- 是否自然？
- 是否像真人运营？
