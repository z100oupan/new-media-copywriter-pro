# Content Frameworks Library v1.0

这是「新媒体运营文案 Pro」的内容运营框架知识库。

目标：

根据内容类型自动选择最合适的运营框架，而不是所有内容都写成一个模板。

适用于：

- 小红书
- 抖音
- 微博
- 微信公众号
- 品牌 Campaign
- 校园运营
- 运营作品集
- 数据复盘

---

# 一、小红书内容框架（重点）

## Framework 01｜种草分享（默认）

适合：

探店、美食、美妆、穿搭、生活方式。

结构：

① 为什么分享（Hook）

② 我的体验

③ 推荐理由

④ 适合谁

⑤ CTA

特点：

像朋友聊天。

不要广告。

---

## Framework 02｜攻略合集

# 八、CTA 放置规则

不同平台位置不同。

小红书：

正文最后一段。

抖音：

最后一句字幕。

公众号：

文末。

微博：

正文最后一句。

海报：

底部行动按钮区域。

# 九、内容长度建议

| 内容类型推荐长度 |            |
| -------- | ---------- |
| 小红书正文    | 300~800字  |
| 探店       | 250~500字  |
| 教程       | 500~1000字 |
| 抖音字幕     | 4~12句     |
| 公众号      | 800~2000字 |
| 微博       | 80~300字   |
| 海报文案     | 30~120字   |

---

# 十、运营输出检查

生成内容前自动判断：

- 内容属于哪个框架？
- 是否符合平台阅读习惯？
- 是否需要标题？
- 是否需要CTA？
- 是否需要标签？
- 是否需要品牌语气？
